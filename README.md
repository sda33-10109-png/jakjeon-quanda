# 🎓 작전 콴다 (Jakjeon Qanda)

작전고등학교 학생들을 위한 **실시간 스터디룸 & 익명/인증 Q&A 서비스**입니다.

## 🌟 주요 기능
1. **학생 인증 및 익명 스위치**: 로그인 후 인증 학생 표시와 익명 모드를 자유롭게 전환할 수 있습니다.
2. **단일 스터디룸 (열품타 모드)**: 실시간 타이머와 함께 집중 공부 시간을 측정할 수 있습니다.
3. **콴다 스타일 Q&A 게시판**: 모르는 문제를 등록하고, 인증 및 익명 답글을 달고 **자신의 답변을 직접 수정**할 수 있습니다.

## 🚀 GitHub Pages 배포 방법
1. 이 리포지토리를 GitHub에 업로드합니다.
2. 리포지토리 **Settings** -> **Pages** 메뉴로 이동합니다.
3. **Source**를 `main` (또는 `master`) 브랜치로 선택하고 **Save**를 누릅니다.
4. 웹 주소가 생성되면 해당 링크로 바로 접속 가능합니다!
